What the conversion does

  • Dropdown values are reduced to their code. The spreadsheet shows "20: Central bank and Corporation" so it is readable; the fixture CSV stores 20, which is what the database holds.
  • Inherited columns are left out. A worksheet shows the fields a table inherits from its parent, but each CSV is loaded into a single table, so those values belong in the parent table's own CSV.
  • Empty cells become NULL, and dates are written in ISO format.
  • Sheets beginning with an underscore are guidance, and are ignored.

Any dropdown value that cannot be matched to a code is written through unchanged and listed in the conversion report, so nothing is lost silently.
